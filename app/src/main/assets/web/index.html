JD-Xi pattern transfer
  • In MIDI Player, enter a slot A01–H64 and the source pattern length. Capture selects it, starts the synth, records one loop and provides a standard four-part MIDI file. Match the transfer BPM to the original program if you want that tempo in the file. Notes, pitch bend and musical controllers are included. Sounds and FX stay on the synth.
  • For import, choose a format 0 or 1 PPQ file with up to four bars on channels 1, 2, 3 and 10. The file supplies the suggested length and initial tempo. Events keep their beat positions at the chosen transfer tempo. Bank/program changes, SysEx and other channels are excluded so the destination stays selected.
  • Prepare a user slot E01–H64. Confirm the slot on the JD-Xi, set the same Pattern Length, select the requested part and arm Real Time Rec. Send that part, then repeat for the other parts without reloading the slot. Audition and use Shift + Menu/Write on the synth to save to the displayed user slot. Cancelling stops transmission; any notes already recorded remain in the temporary program.


Step sequencer
  • Choose a track and tap to add notes, or drag horizontally across a pitch to draw one sustained note. Drag from an existing note to resize it. On Drums, dragging paints separate hits. Enable Erase notes above the grid and tap or sweep over notes to remove them, including by their tails. Columns are sixteenth notes; the bold divisions mark beats. Select a bar for patterns longer than 16 steps. Melodic tracks show two octaves at a time; Drums uses the kit pads on channel 10. Velocity and length apply to newly added notes. Drum hits last one step.
  • Play loop sends all unmuted tracks to the MIDI output. Swing delays alternate steps. Enable Send MIDI clock + start/stop to run the JD-Xi sequencer alongside it in SLAVE mode. Stop the Performance transport before starting the step sequencer.
  • The current pattern is saved in this browser. Use the eight slots for alternate versions. Mute, notes, tempo, swing and loop length are saved with each slot. Shortening the loop keeps later notes available when you extend it again.
  • To record into the synth, arm recording on the JD-Xi and send a timed pass for one track or all unmuted tracks. Set the destination length on the synth first, then write the program there to keep it.


FX
  • Connect the JD-Xi input and output with SysEx permission, then open FX or press Read FX from JD-Xi. Controls become available as their values arrive. Read again after changing a program or editing an effect on the synth.
  • Choose a destination for each part and adjust its delay and reverb sends. Direct bypasses the effects. In the drum kit’s KIT routing mode, individual drum sounds use their own routing. Select KIT on the synth to restore that mode.
  • Effect 1 and Effect 2 each have one type per program. You can adjust their levels and sends, route Effect 1 into Effect 2, and adjust the shared delay and reverb levels. To separate two sounds, route one part to Effect 1 and the other to Effect 2, then set Effect 1 output to Direct.
  • Edits change the synth’s temporary program. Use Write on the JD-Xi to keep them. Click any heading on FX or Step sequencer to collapse its section. All sections start expanded and this browser remembers your choices.


Getting connected
  • Connect the JD-Xi by USB, switch it on, then press Connect USB MIDI in the header and allow the browser's MIDI + SysEx permission.
  • Works in Chrome, Edge and Brave on desktop and Android. iPhone/iPad browsers have no Web MIDI, so the app cannot talk to the synth there.
  • The page must be served over https (or localhost). Close other programs or tabs that may be holding the JD-Xi (DAW, JDXi_Manager).
  • MIDI connection & channels (folded at the top): choose output/input port, refresh devices, send a test note, test that the JD-Xi answers, and see the MIDI log. It opens by itself if a connection error occurs.


Header
  • Install app: adds the page to your home screen as an app (Android shows the install prompt; iOS shows how to do it from Safari).
  • Appearance remembers your theme in this browser. Studio Keys pairs a warm grey panel with colour-coded mixer channels. Pocket LCD uses graphite keys and a green instrument display.
  • Disconnect: releases the MIDI ports.


Visualizer
  • The Visualizer is enabled by default at the top of the app, above the tabs, on every page. Untick Visualizer to hide it with one click. Press Full screen (or F) to show only the display, e.g. as a visual backdrop: tap the picture or use the arrow keys/space to change view, Esc exits, and the screen is kept awake where the browser allows it. Views: Tape deck (greyscale cassette with an endless tape loop that keeps circulating while the synth plays, VU meters and transport), Spectrum per part (Digital 1, Digital 2, Analog, Drums in their own colours), Oscilloscope, MIDI mixer (shows the real mixer faders with activity meters), Particles, Piano roll (vertical waterfall: keyboard on top, notes fall downwards), Step sequencer (16 steps per part, synced to the pattern), Pattern display, Channel activity, a Dashboard with six views at once (best in full screen), plus Part orbs, Radial and Auto-cycle
  • Browsers get no audio over MIDI, so the visuals are driven by the notes the app sends and the notes the JD-Xi sends back (play on its keyboard or run its sequencer/arpeggiator). Use JD-Xi audio optionally analyses the JD-Xi's USB audio input for a real spectrum and scope; it is only analysed, never played, and needs microphone permission.


Slider buttons
  • Tick −/+ buttons on sliders (offered in the mixer and on the Synth page) to get a − and + button beside every slider for exact one-step changes; hold a button to repeat. The setting is shared by all menus and remembered in this browser.


Mixer
  • Always visible at the top: level for Synth 1 (Digital 1), Synth 2 (Digital 2), Analog and Drums, written to the JD-Xi part levels. M mutes a part, S solos it.
  • Faders show the JD-Xi's current levels after connecting. A pattern change on the Performance page loads a new program on the synth; with Keep my mix ticked the parts you moved keep your levels, otherwise the levels are read again from the new program.


Performance
  • Six slots for your own patterns (JD-Xi programs A01–H64; they start as A01–A06). Set a program code and the pattern length in bars for each slot.
  • Tap a slot to start it. While something plays, tap another slot to make it next: the current pattern plays to its end and the next one takes over on the downbeat, so nothing is cut off. Tap a queued slot again to cancel; with nothing queued the current pattern loops.
  • Now / Next shows what is playing, the bar and beat, and what is queued.
  • Clock: This app sends clock (JD-Xi Sync Mode = SLAVE) starts the sequencer and keeps the tempo you set. Follow the JD-Xi clock (Sync Mode = MASTER) lets you start on the synth while the page counts its clock.
  • Program channel must match the JD-Xi's Program Control Channel. Switch lead sets how many ms before the downbeat the program change is sent. Keep clock while stopped supplies tempo for panel Play in SLAVE mode. Incoming MIDI Start aligns the playhead. If Start is missing, three separate drum strikes can indicate playback when silence detection is enabled. This estimate can also respond to manual drum playing. Melodic-only patterns without Start can be launched from the app for accurate position. Stop on MIDI silence is enabled by default when the app sends clock. After repeated incoming notes it stops playback after two quiet beats (at least one second). Disable it for long rests. An incoming MIDI Stop stops playback immediately. Stop stops the app clock; Panic sends all-notes-off on every channel.


Synth (tone editor)
  • Active patch overview: pick a part (Digital 1, Digital 2, Analog) and partial, then Read active patch to load the sound from the JD-Xi. Oscillator, filter, filter/amp envelopes, LFO and tone-common controls then send changes live.
  • Essentials only shows the key controls; Edit all 3 partials together applies a change to every partial; Edit without readback allows editing before the patch has been read.
  • Advanced: the full parameter editor, block by block (Digital 1/2, Analog) with read and write of every parameter.
  • Arpeggio: its own category on the Synth page with the arpeggiator settings (style, motif, grid, duration, octave range, accent, velocity).
  • Keyboard: on-screen piano for the chosen part (including Drums), with octave shift and velocity. Drag across keys to glide, use several fingers for chords, or play from the computer keyboard (A S D F G H J K for white keys, W E T Y U for black). All notes off silences stuck notes.


My patches (Synth page)
  • Save current sound reads every parameter of the active tone of Digital 1, Digital 2 or Analog from the JD-Xi and stores it in this browser under the name you give (or the tone's own name), together with the preset it came from.
  • Star a patch to make it a favourite (favourites are listed first). Load sends all parameters back to the temporary tone and checks them by reading back; Digital patches can be loaded into either Digital part.
  • Export gives JSON (all, favourites or one patch, re-importable) or a .syx file for a single patch. Drum kits are not included. Storage is per browser, so export now and then as a backup.


Patches
  • Browse the built-in Digital, Analog and Drum presets for the selected part and search by name, number or category.
  • Tap a preset, or enter a number and press Load patch, to send Bank Select + Program Change to the JD-Xi.
  • Save favorite stores the current choice in the Favorites list (kept in this browser).


DX7 Import
  • Open a Yamaha DX7 .syx file (single voice or 32-voice bank), pick a voice and read the analysis: algorithm, which operators become JD-Xi partials, and how bright the FM sound is.
  • Send to JD-Xi writes the matching settings (name, partials, waveform, pitch, filter, envelopes, LFO, pitch envelope) to the active temporary tone of Digital 1 or Digital 2. Untick a group to leave that part of the sound alone.
  • The previous sound is read first so Undo import can restore it; afterwards the app reads back and tells you how many values the JD-Xi confirmed. It is an approximation: FM and subtractive synthesis differ, so expect to fine-tune on the Synth page.
MIDI Player
  • Load a standard MIDI file (.mid, format 0 or 1). Play file sends its events to the JD-Xi using the file's tempo changes; Stop file ends playback and Loop repeats it.
  • There is no seeking, channel remapping or timeline.


Good to know
  • Edits are made to the JD-Xi's temporary program. Save the program on the synth itself if you want to keep a change.
  • Favorites, performance slots and theme are stored in this browser only.
  • If nothing happens, open MIDI connection & channels at the top of this Info page and check the log, the selected ports and the SysEx permission.
Requires HTTPS or localhost, and a browser with Web MIDI + SysEx permission (typically Chrome or Edge on desktop).
